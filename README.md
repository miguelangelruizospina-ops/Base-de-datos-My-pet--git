# Base de datos Mi Pet

## Descripción

Base de datos del proyecto **Mi Pet**, desarrollada para almacenar y gestionar la información relacionada con usuarios, mascotas y las diferentes funcionalidades de la aplicación.

## Gestor de base de datos

* **MySQL**
* Base de datos: `mypet`

## Tablas principales

La base de datos está estructurada mediante diferentes tablas relacionadas entre sí para organizar la información del sistema:

* `usuario`
* `perfil_usuario`
* `mascota`
* `perfil_mascota`
* `historial_medico`
* `evento`
* `recordatorio`
* `documento`
* `administrador`
* `servicio`
* `publicacion_foro`
* `emergencia`
* `notificacion`

## Relaciones

Las tablas utilizan claves primarias y claves foráneas para mantener la integridad de los datos y establecer las relaciones entre usuarios, mascotas y las diferentes funcionalidades de la aplicación.

## Objetivo

La base de datos permite almacenar de manera organizada la información necesaria para el funcionamiento de **Mi Pet**, facilitando la gestión de usuarios, mascotas, historial médico, eventos, recordatorios, documentos, servicios, emergencias y notificaciones.

## Tecnologías

* MySQL
* XAMPP
* Java
* Spring Boot
* JPA / Hibernate

## Proyecto

**Mi Pet** — Sistema integral para la gestión y cuidado de mascotas.
